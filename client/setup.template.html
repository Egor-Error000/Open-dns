AI-сайты через SmartDNS

Настройка Firefox и YogaDNS для Codex, Cursor, ChatGPT, Claude, OpenRouter, Grok и других включённых сайтов.

1. Адрес сервера

Сервис доступен из любой IPv4-сети без регистрации IP и без ключей доступа. Используй этот адрес DNS over HTTPS:

__DOH_URL__

При смене Wi-Fi или переходе на мобильный интернет повторная регистрация не требуется. Через TLS-реле идут только выбранные сайты. Firefox может отправлять этому серверу DNS-запросы и для остальных сайтов.

2. Firefox на Windows

1
Открой Настройки → Приватность и защита → DNS через HTTPS.
2
Выбери Персональный и вариант Другой URL. Вставь:
__DOH_URL__
3
Включи предупреждение, если безопасный DNS недоступен. Закрой и снова открой вкладку.
4
Открой Wikipedia, затем нужный AI-сайт. Проверь вход и короткий текстовый запрос.
Успех: страница и ответ открылись; Firefox не показывает ошибку сертификата. Не добавляй исключения сертификатов.

Firefox DoH настраивает только браузер, а не приложения Codex или Cursor.

3. YogaDNS на Windows — для приложений

Скачай YogaDNS с официального сайта. До изменений сохрани текущий профиль: File → Export Configuration to….

1
Открой Configuration → DNS Servers → Add. Имя: SmartDNS; тип: DNS over HTTPS; URL:
__DOH_URL__
Если отдельно запрошен IP — __SERVER_IPV4__ без порта. HTTPS использует порт 443.
2
Нажми проверку сервера. Если она не проходит, проверь URL сервера и доступность сети.
3
Создай правило AI через SmartDNS. Вставь список ниже в Hostnames. Действие Process, сервер SmartDNS. Перемести правило выше Default. Default оставь своим обычным DNS; резервный пул этому правилу не назначай.
4
Включи правило и проверь журнал YogaDNS: например, chatgpt.com должен обрабатываться правилом AI; example.com — правилом Default.
Домены для поля Hostnames

YogaDNS принимает разделители «;» и перенос строки. Нажми копирование и вставь список в новое правило.



Если DNS перестал работать, восстанови сохранённый профиль через File → Import Configuration from… Не отключай проверку TLS.


4. Firefox на Android
1
Подключись к Wi-Fi или мобильной сети с доступом к IPv4.
2
В Firefox нажми ⋮ → Настройки → Приватность и безопасность → DNS через HTTPS. Выбери постоянную защиту и, если доступно, свой DNS URL:
__DOH_URL__
3
Открой Wikipedia и AI-сайт в Firefox и выполни короткий текстовый запрос.
Некоторые версии Firefox Android не позволяют указать собственный DoH URL. Тогда DNS доступен только в Firefox на Windows, пока владелец не настроит телефон отдельно. Системный Android Private DNS использует другой протокол.
Справка Mozilla: Firefox на компьютере и Firefox для Android.


5. Если не работает
  • Проверь интернет-соединение и доступность сервера.
  • Убедись, что DoH URL точный и заканчивается на /dns-query.
  • В YogaDNS проверь порядок правила, действие Process и сервер SmartDNS.
  • Полностью перезапусти браузер или приложение после изменения DNS.
  • Сообщи владельцу текущий внешний IP, приложение и текст ошибки. Не отправляй пароли, API-ключи или содержимое почты.
Доступ аккаунта, подписки и API зависит от провайдера. Работа DNS не гарантирует, что любой аккаунт сможет войти из любой страны.
